This repo is the public home for Steward users: the user guide, bug reports and feature requests. The app itself is not open source and its code is not here.

## Quick start

1. Install Steward from Google Play. It runs on Android 10 or newer.
2. Pick a plan: Steward for 2 phones, Pro for up to 10, or Unlimited for every phone you have. Each starts with 3 days free from Google Play.
3. Allow notifications, so gate, delay and boarding alerts can reach you.
4. Tap the add button and type a flight number, or find your flights in the calendar, or share a booking or boarding pass to Steward.
5. From two hours before departure, the gate and times sit live on your lock screen.
6. Settings, Ready for your trips, shows anything that is off, with a Fix button.

## Report a bug or ask for a feature

1. Search the [open issues](https://github.com/Zanoshky/steward-app/issues) first. If yours is there, add a thumbs up or a comment.
2. Otherwise open a [bug report](https://github.com/Zanoshky/steward-app/issues/new?template=bug_report.yml) or a [feature request](https://github.com/Zanoshky/steward-app/issues/new?template=feature_request.yml).
3. Add your app version, phone model and Android version, and a screenshot if you can. Crop out anything private first, like your name, seat and boarding pass barcode: issues are public.

Prefer email? Write to support@zanoski.com.
